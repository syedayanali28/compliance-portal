Validation rules

Which kind of rule do I need?

Connection rules
Use these when the diagram draws a line between two components. The check runs on that relationship: from type and zone, to type and zone, and whether the link crosses a boundary you care about. Example: blocking a flow from an internet-facing piece into a restricted area unless policy says otherwise.
Placement rules
Use these when a single component sits inside a zone and you need to allow or forbid that combination. The check runs on the shape and where it lives, not on a line to another shape. Example: a given component type must not appear inside a particular zone.
